# Space Debris Detector

Учебный проект по разработке полезной нагрузки для Orbicraft.

Система имитирует обнаружение космического мусора с помощью ультразвукового дальномера HC-SR04. Arduino измеряет расстояние до объекта и определяет, находится ли он в опасной зоне.

Если объект приближается на расстояние 20 см или меньше, система включает красный светодиод и постоянный звуковой сигнал.

Если объект находится дальше 20 см, включается зелёный индикатор, а звуковая тревога отключается.

Проект также предусматривает передачу телеметрии в Orbicraft через UniCAN.

## Возможности

- измерение расстояния с помощью HC-SR04;
- обнаружение объекта в опасной зоне;
- зелёная индикация безопасного состояния;
- красная индикация опасности;
- постоянный звуковой сигнал при обнаружении объекта;
- вывод расстояния в Serial Monitor;
- передача телеметрии через UniCAN;
- интеграция с Orbicraft.

## Использованные компоненты

- Arduino UNO;

## Запуск

1. Подключить компоненты по схеме.
2. Открыть файл `space_debris_detector.ino` в Arduino IDE.
3. Установить необходимые библиотеки для UniCAN.
4. Подключить Arduino.
5. Выбрать правильную плату и COM-порт.
6. Загрузить программу.
7. Открыть Serial Monitor на скорости `9600 baud`.
8. Поднести объект к HC-SR04.

При расстоянии 20 см или меньше должна сработать система тревоги.

## Передаваемые данные

Телеметрия отправляется через UniCAN с заданным интервалом.

Передаются:

- расстояние до объекта;
- состояние системы: `SAFE` или `DANGER`.

## Назначение проекта

Проект является учебной имитацией системы обнаружения объектов рядом с космическим аппаратом.

HC-SR04 не является настоящим датчиком космического мусора и используется только для демонстрации принципа обнаружения приближающегося объекта.
